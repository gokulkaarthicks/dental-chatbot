The module is organized around a single FastAPI app assembled by `app/main.py:create_app`, which wires observability middleware (request-id propagation, timing, structured error responses), CORS, and the six API routers under `/api`. Startup triggers `bootstrap.bootstrap_database`, which delegates to `db.create_db_engine` / `session_scope` for a SQLite engine with per-connection pragmas (WAL, foreign_keys, busy_timeout) and runs additive migrations via `migrations.apply_additive_migrations` — an idempotent schema reconciler that adds missing columns from `_ADDED_COLUMNS`, rebuilds the `appointments` table when its CHECK constraint changes (SQLite limitation), and creates missing indexes from `_REQUIRED_INDEXES`. Seed data lives in `seed_fixtures.py` as frozen dataclasses plus a `SeedPlan` bundle; it is only auto-inserted on an empty database. The CLI (`cli.py`) exposes `init`, `seed`, `reset-demo`, and `demo-status` subcommands through `argparse`, reusing the same bootstrap/seed services. Settings are centralized in `config.py` as a frozen `Settings` dataclass loaded from `.env` then environment variables, cached via `lru_cache(maxsize=1)`. `server.py` is the thin Uvicorn launcher used as the container/module entry point. Dependency direction is one-way: server → main → bootstrap → db/migrations/seed → models/services; nothing in the stack imports back into the HTTP layer.
