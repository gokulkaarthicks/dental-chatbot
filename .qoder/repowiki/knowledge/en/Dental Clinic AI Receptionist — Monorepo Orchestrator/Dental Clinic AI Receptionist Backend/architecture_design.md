The backend is layered around a FastAPI app factory in `app/bootstrap.py` / `server.py`: `api_routes` (routers under `app/api/`) depend on `business_services` (domain logic under `app/services/`), which in turn operate on `data_models` (SQLAlchemy tables under `app/models/`) backed by a shared SQLite engine from `app/db.py`. The `agent_orchestration` layer (`app/agent/`, `app/ai/deepseek.py`) plugs into this stack via the same service/model contracts to drive conversational tools for booking/rescheduling. `bootstrap_cli` owns startup: it creates the DB, runs Alembic-style migrations via `app/migrations.py`, seeds fixtures through `app/seed_fixtures.py`, then launches Uvicorn. `tests/` reuses the same bootstrap path against an ephemeral SQLite file, so integration tests exercise the full stack end-to-end.
