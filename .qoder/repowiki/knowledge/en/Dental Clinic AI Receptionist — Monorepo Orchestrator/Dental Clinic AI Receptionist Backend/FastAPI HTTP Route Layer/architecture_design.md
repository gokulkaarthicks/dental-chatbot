Each file under `app/api/` defines a FastAPI `APIRouter` (prefix + tags) that is mounted at the application root; `__init__.py` re-exports the public routers (`chat`, `clinic`, `demo`, `health`) so they are discoverable by the app factory. Authentication is centralized in `deps.py`: `CurrentPatientSession` resolves an opaque `X-Patient-Session` header against `patient_sessions`, while `CurrentStaffSession` / `CurrentStaffUser` resolve an HttpOnly cookie plus CSRF header for state-changing requests, enforcing SameSite=Lax and rejecting staff credentials on patient routes. Business logic lives outside this module in `app.services.*`; route handlers only parse payloads, call services, and map results to Pydantic schemas from `app.schemas`. Blocking work (LLM calls, heavy DB queries) is offloaded via `starlette.concurrency.run_in_threadpool`. The dependency direction is strictly: routes → deps → services → models/db; routes never import each other's routers.
