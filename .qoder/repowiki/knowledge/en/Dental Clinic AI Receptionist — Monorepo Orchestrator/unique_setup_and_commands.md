`make dev` is the primary workflow — it runs `docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build`, giving hot-reload for Python and TSX while keeping the same image topology as production. `make seed` inserts fixtures without deleting records; `make reset-demo` recreates the demo DB; `make hooks` installs the pre-push git hook that runs `scripts/check-before-push.sh`.
