Three-layer leaf: `ChatPage.tsx` is the presentational shell (two-column layout with practice sidebar + thread), `useChat.ts` owns all conversation state and persistence, and `components/chat/` holds the two UI primitives (`Composer` for input + voice dictation, `MessageBubble` for rendering turns plus inline feedback). The hook is the single source of truth — it manages session bootstrap, SQLite-backed transcript restoration via `sessionStore`, optimistic message insertion, error recovery, and delegates interactive scheduling cards to `useCardActions` / `CardStack`. Dependency direction is one-way: page → hook → API clients (`chatApi`, `schedulingApi`, `api`) and shared libs (`lib/sessionStore`, `lib/cards`, `lib/liveCards`); components never call APIs directly. A module-level `bootPromise` guard ensures React 18 StrictMode's double mount does not create two sessions, and a `BootSnapshot` lets the second mount render the first mount's resolved thread without refetching.
