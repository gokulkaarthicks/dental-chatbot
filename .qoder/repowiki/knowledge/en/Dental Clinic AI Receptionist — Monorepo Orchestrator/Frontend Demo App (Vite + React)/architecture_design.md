The app is a single-page React application bootstrapped from `src/main.tsx` and built by Vite (`vite.config.ts`). Two top-level pages coexist: `pages/OverviewPage.tsx` (patient) and `pages/staff/StaffApp.tsx` (receptionist), each consuming the same shared layer — `api/` HTTP clients, `hooks/` for chat/card/session state, and `lib/` utilities like `sessionStore.ts`. Cross-child wiring happens through these shared modules rather than direct page-to-page imports. The build output in `dist/` is served by an nginx container configured via `nginx.conf`, with `Dockerfile` and `.dockerignore` defining the deployment image. Styles are centralized under `styles/global.css` and component-scoped CSS files consumed by both patient and staff UIs.
