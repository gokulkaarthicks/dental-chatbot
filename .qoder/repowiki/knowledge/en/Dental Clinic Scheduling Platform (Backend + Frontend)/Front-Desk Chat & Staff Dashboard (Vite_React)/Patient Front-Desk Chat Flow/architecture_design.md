Three-layer leaf with one-way dependency direction: `ChatPage.tsx` is the presentational shell (two-column layout with practice sidebar + scrollable thread), `useChat.ts` owns all conversation state and persistence, and `components/chat/` holds two UI primitives -- `Composer` for text input plus Web Speech API voice dictation, and `MessageBubble` for rendering turns plus inline thumbs-up/down feedback. The hook is the single source of truth: it manages session bootstrap, SQLite-backed transcript restoration via `sessionStore`, optimistic message insertion, error recovery, and delegates interactive scheduling cards to `useCardActions` / `CardStack`. Components never call APIs directly; they receive data and callbacks as props. A module-level `bootPromise` guard ensures React 18 StrictMode's double mount does not create two sessions, and a `BootSnapshot` lets the second mount render the first mount's resolved thread without refetching. Persistence contract: only token + active conversation id live in `sessionStore`; every mount restores from them, and `applyConversation` is the sole path that writes both the stored pointer and the rendered thread.
