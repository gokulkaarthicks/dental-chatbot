Self-contained single-screen app with no client-side router. `StaffDashboard.tsx` owns chrome (sidebar + header) and renders one of six section components from `sections/` based on an in-memory `StaffView` state mirrored to the URL hash (`#/{view}`), so reloads and back/forward work. `StaffAuthContext.tsx` provides a `StaffAuthProvider` / `useStaffAuth` context; it treats the server as the sole source of truth by calling `GET /api/staff/session` on mount and on tab focus. `useStaffData.ts` centralises data access: `useStaffQuery` fetches with loading/error/refreshing state keyed by a stable string, and `useStaffMutation` wraps writes, broadcasting changes through a module-level `notifyStaffDataChanged` version counter so every mounted query reloads. Three sync mechanisms keep the dashboard fresh without WebSockets -- mutation-driven invalidation, `focus`/`visibilitychange` listeners, and a 20-second visible-tab poll (`STAFF_POLL_INTERVAL_MS`). Each section component composes its own queries/mutations and reuses shared presentational helpers from `StaffUi.tsx`. Styles live in `staff.css` under the `sd-*` namespace.
